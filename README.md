# Balenciaga Sneakers Marketplace (TypeScript)

![Preview](marketplace-balenciaga-ts.png)

Интернет-магазин кроссовок Balenciaga на React + TypeScript.

## Что умеет
- 🛒 Добавление/удаление товаров в корзину
- 💾 Сохранение корзины в localStorage
- 🔍 Поиск по названию
- 🌓 Тёмная/светлая тема
- 📱 Адаптивная вёрстка
- 📦 Полная типизация (TypeScript)

## Стек
- React 18
- TypeScript
- CSS Modules
- Vite
- Phosphor Icons

## Как запустить
1. `npm install`
2. `npm run dev`
